# （株）イヤーズ デモアプリ（申請書・見積書作成）

介護保険の住宅改修の申請書と平面図を作るアプリのデモ版です（2026-11-12 から、工事見積書・理由書は出しません）。

- 開く URL：https://akamar08taiyo-bot.github.io/years-demo/
- 入れたデータは、その端末（ブラウザ）の中だけに保存されます。どこにも送りません。
- 使える期限・止めるスイッチは `status.json` です。
  - `"until": "2026-12-31"` … この日まで使えます（翌日から開けません）。延ばすときは日付を書きかえます。
  - `"enabled": false` にすると、すぐ（開き直したとき・開いている画面も30分以内に）使えなくなります。
  - `"message"` に文を入れると、使えないときの画面にその文を出します。
- `index.html`・`version.json` は、アプリの元のリポジトリでビルドしたものです（`npm run build:years`）。ここでは直さないでください。
